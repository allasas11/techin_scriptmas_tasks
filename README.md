# Christmas TECHIN Programming Challenge 2025

This repository contains solutions to 22 tasks completed as part of a course selection process.

## Structure
- Each task is stored in its own folder
- Technologies used depend on task complexity:
  - JavaScript
  - TypeScript
  - React (Vite)

## How to run
- Plain JS tasks: open `index.html`
- TS tasks: `npm install && npm run build`
- React tasks: `npm install && npm run dev`


## Branch Strategy

- `main`: stable branch containing only the core project.  
- `develop`: integration branch for completed tasks.  
- `task-XX-*`: feature branches for individual tasks, merged into `develop` upon completion.
