## 🌿 Branch Strategy

This repository follows a professional Git workflow:

- **`main`**
  - Final, stable version of the project
  - Contains all completed tasks

- **`develop`**
  - Integration branch where all tasks are merged after completion

- **`task-XX-*`**
  - Individual feature branches for each task
  - Example: `task-06-sleigh-schedule`
  - Each task was implemented, committed, and merged separately

This approach demonstrates:
- understanding of Git branching
- clean commit history
- real-world development workflow
